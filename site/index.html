A few things to know

When does the timer pause?

When your browser window loses focus, your computer locks, or there has been no input for 60 seconds. You can also pause it yourself. Passive reading and fullscreen video pause after that idle threshold, too.

What about multiple screens and profiles?

Only the focused browser window’s active website is eligible. Each browser profile keeps its own history; there is no combined cross-profile dashboard. The extension measures browser focus, not which screen your eyes are looking at.

How do I try it?

The Chrome Web Store release is being prepared. For now, follow the manual installation instructions on GitHub. No build step is needed.
